# 🚀 TaskFlow

Aplicação moderna de gerenciamento de tarefas desenvolvida com HTML5, CSS3 e JavaScript.

## ✨ Funcionalidades

- ✅ Criar tarefas
- ✏️ Editar tarefas
- 🗑️ Excluir tarefas
- ✔️ Concluir tarefas
- 🔍 Busca em tempo real
- 📊 Estatísticas automáticas
- 🌙 Dark Mode
- 💾 Persistência com LocalStorage
- ↕️ Drag and Drop
- 📱 Responsivo

## 🛠 Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage
- ToastifyJS
- SortableJS
