# Matheus Correia - Lista de Tarefas

Estruturei a Lista de Tarefas com HTML5; Criei uma estrutura básica com um input para adicionar tarefas e uma lista dinâmica para exibi-las. Estilizei com CSS3, desing simples moderno e a fonte usada é Poppins do Google Fonts, na parte da lógica fiz com JavaScript e criei a função para adicionar uma tarefa na lista dinamicamente, o código tambem captura o texto digitado e cria um novo item na lista e também adicionei um evento para deletar tarefas ao cliclar no botão ❌
